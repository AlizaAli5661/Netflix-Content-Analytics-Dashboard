## 📌 About the Project

The **Netflix Content Analytics Dashboard** is an interactive data visualization project built using **Microsoft Power BI**.

The project analyzes Netflix movies and TV shows to understand content distribution across different **types, ratings, countries, genres, and release years**.

The dashboard converts raw Netflix data into an interactive visual report, making it easier to identify patterns, trends, and key characteristics of the Netflix content library.

---

## 🎯 Project Objectives

The main goals of this project are:

- 📊 Analyze the overall Netflix content library
- 🎬 Compare Movies and TV Shows
- 🌎 Analyze content distribution across countries
- ⭐ Explore content ratings
- 🎭 Identify the most common genres
- 📅 Understand content trends over time
- 🔎 Create an interactive dashboard for easy data exploration
